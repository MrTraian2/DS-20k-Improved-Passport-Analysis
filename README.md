# DS-20k-Improved-Passport-Analysis
vPDU characterization functions, finger analysis, and signal reconstruction


DarkSide-20k code for the characterisation, analysis and defect studies part of "Pulse Count Rate Measurements and Defect Correlation of Veto
Photon-Detector Units for the DarkSide-20k Experiment" by Traian Tus

The work was performed in collaboration with the DS-20k team, with the scope of improving noise detection and analysis artefacts, reduce external photon backgrounds and enhance acquisition and analysis across vPDU devices

Defect Analysis data, correlations and ML recognition still in progress and not included
